# BRING 건물 설비지도 · 첫 구현

## 회사 FM 건물정보 연결 (이름·주소만)

FM 상단 `건물정보 내보내기` → 로그인한 FM에 표시된 건물 선택 → 이름·주소 미리보기 → JSON 저장. 3D 설비지도 왼쪽 `FM 건물정보 가져오기` → 파일 선택 → 미리보기 확인 → `확인한 건물 추가 / 열기`.

전화번호·건물주·계약·금액·메모는 내보내지 않는다. 예상하지 못한 항목이 든 가져오기 파일은 거절한다. 기존 건물은 유지하며 동일한 FM 이름·주소는 이미 만든 지도로 열린다. 설비는 빈 상태로 추가하고, 최초 1층·16×12m·지하 1층은 표시용 임시 모형이다. 실제 규모는 건물 설정에서 입력해야 한다. 로그인된 FM의 기존 로딩 데이터를 사용하며 새 Firebase 조회나 쓰기는 하지 않는다. 로그인 만료 시 내보내기를 차단한다.

이 연결은 자동 서버 동기화가 아니다. JSON 파일과 브라우저 저장 자료는 사용자가 보관해야 한다. 실제 서버 보안 규칙의 적용 상태는 이 기능에서 검증하거나 변경하지 않는다.

별도 서버로 검증할 때는 `ATLAS_TEST_URL=http://localhost:59484` 환경값을 사용한다. 브라우저 테스트는 실제 로그인 세션과 분리되며 CRM 연결 테스트의 외부 네트워크는 차단한다.

## 입력창 화면 검증

등록·수정창은 입력 영역만 스크롤하며 저장하기·닫기 버튼은 고정 표시한다. `layout-browser.cjs`는 높이 720px, 너비 390·768·1110·1280·1440px에서 가로 넘침과 입력 전후 버튼 노출을 검사한다. 실제 브라우저 데이터와 분리된 테스트 세션을 사용한다.

## 다른 층으로 복제

설비 상세 `다른 층에 복제`에서 선택 설비 하나 또는 원본 층의 설비·공간 전체를 선택한다. 대상 층과 생성 개수를 확인한 뒤 복제한다. 3D 모양·좌표·입력 항목 이름을 복사하고, 복제 대상 내부 연결은 새 번호로 연결한다. 외부 연결은 복사하지 않으며 재지정 개수를 알려준다. 다른 층에 걸친 경로와 사진·문서·실제 값·점검 이력·비용·일정은 복사하지 않는다. 새 기록은 추정·확인 필요 상태다. 원본 층과 건물은 보존한다.

## 설비 종류로 등록

`＋ 기록 등록`의 설비 종류에서 펌프, 물탱크·저수조, 밸브, 배수구·집수정, 분전반, 소화기, 실외기를 선택한다. 해당 3D 모양과 데이터 영역, 권장 입력 항목이 설정된다. 기존에 입력한 이름과 상세 값은 유지하고 부족한 항목만 추가한다. 일반 문서·업무 기록은 기본 표시를 사용한다. 위치와 건물 크기는 소수점 입력이 가능하다. 층수는 정수만 허용된다.

## 보고서와 전체 백업

상단 `보고서·전체 백업`에서 선택 건물 점검 보고서를 HTML로 내려받는다. 파일을 열어 인쇄/PDF 저장이 가능하다. 미확인·조치 필요 설비, 점검 일정, 작업 내역·비용, 설비 확인 근거를 포함하며 임대차 상세와 사진 원본은 보고서에 넣지 않는다.

전체 백업은 모든 건물과 사진·평면도·경로·작업 이력을 포함한다. 복원 시 파일을 검증하고 건물 목록을 미리 보여준 뒤 사용자가 추가 버튼을 누르면 반영한다. 기존 건물은 유지하며 충돌하는 ID는 새 ID와 복원 사본 이름으로 추가한다. 전체 백업 가져오기는 최대 30MB, 합계 최대 100개 건물이다. 브라우저 저장공간이 부족하면 저장을 거절하고 기존 자료를 유지한다. 기존 상단 `백업 저장`은 선택 건물만 내보내는 기능이다.

## 점검 현황

상단 `점검 현황`에서 등록 설비·현장 미확인·예정일 경과·오늘 점검·입력 수리비를 확인한다. 조치 필요/미확인/경과/전체 일정 필터를 제공한다. 설비명을 누르면 3D 상세로 이동한다. 설비 상세의 `다음 점검 설정`에서 날짜와 담당자를 지정하고 날짜를 비우면 해제한다. 점검 기록 추가는 예약 날짜를 자동 변경하지 않는다. 자동 알림은 미연결이다.

등록 설비 집계는 급배수·전기·소방·냉난방·센서 영역을 대상으로 한다. 일정과 비용은 모든 기록의 입력값을 사용한다. 비용 미입력 건수와 예시 건물 여부를 함께 표시한다.

## 처음 사용하는 경우

3D 아래 `처음이라면 · 건물 둘러보기`를 선택한다. 건물 전체 → 펌프실 → 급수 계통 → 분전반 → 소방 → 호실 → 첫 현장 기록 순으로 안내한다. 등록되지 않은 설비 단계는 생략한다. 단계의 `점검 기록 남기기`는 해당 설비의 기존 기록 입력창으로 연결된다. 종료하면 원래 층과 표시 설정으로 돌아간다. 건물 전환 시 안내는 종료된다. 안내 진행만으로 설비 상태나 현장 확인 여부를 변경하지 않는다.

## 도면 없이 예시 건물로 시작

왼쪽 `도면 없이 시작하기`에서 4층 계단형 다가구 또는 3층 근린상가를 선택한다. 각각 별도 건물로 추가되며 기존 자료를 덮어쓰지 않는다. 재선택은 해당 예시를 다시 열기만 하고 수정사항을 초기화하지 않는다.

호실·계단·공용복도·저수조·펌프·밸브·급배수 입상관·분전반·소화기·실외기와 각 데이터 영역 예시를 포함한다. 다가구는 16개 호실, 근린상가는 12개 공간을 가진 가상 설계다. 설비 유무·규격·배치와 연결은 실제 건물을 검증한 결과가 아니다. 층을 선택하면 해당 층으로 카메라가 맞춰지고, 호실을 클릭하면 임대차 입력 항목이 열린다.

`?example=house` 또는 `?example=shop` 링크로 해당 예시를 열 수 있다. 최초 선택 시 브라우저에 저장된다.

FM 상단 `3D 설비지도` 또는 `/building-operations/`에서 연다. 실제 3D, 회전, 층 분리, 레이어 선택, 설비 선택, 10개 영역 기록 등록·수정·삭제를 제공한다.

## 데이터 등록

정보 수정에서 층 또는 X·Z 좌표를 변경하면 확인 수준을 추정으로 바꾸고 확인일을 비운다. 해당 설비로 들어오거나 나가는 경로의 확인 표시도 해제한다. 기존 근거 문구에 재확인 안내를 추가하며 점검 이력·사진·다른 설비의 경로는 유지한다. 메모만 변경하면 기존 확인 상태를 유지한다. 재확인은 위치 저장 후 별도로 수행한다.

1. 왼쪽 관리 건물에서 건물을 추가하거나 전환한다. 건물 설정에서 이름, 주소, 층수, 치수를 입력한다. 각 건물은 지하 1층을 포함한다.
2. 기록 등록에서 영역을 선택하고 이름·층·좌표·상태를 입력한다.
3. 실제 설비의 모델·규격·사진 URL·도면 URL·확인일·근거를 입력한다. 상세 항목은 `항목: 값` 형식으로 자유롭게 추가한다.
4. 연결 설비를 선택한다. 이는 사용자가 입력한 연결 정보이며 실제 차단범위나 수리명령을 보증하지 않는다.
5. 설비 상세의 사진 첨부에서 대표 사진을 등록한다. 점검 기록에서 날짜·담당자·비용·작업 내용을 누적한다.
6. 배관 경로에서 연결 설비를 선택하고 층, X, Z 형식으로 중간 지점을 입력한다. 경유점을 입력하고 양쪽 설비 모두 현장 확인 상태인 경로는 실선 배관으로 표시한다. 자동 경로는 점선이다.
7. 백업 저장으로 현재 선택 건물의 JSON을 보관한다. 가져오기는 선택 건물을 교체하므로 먼저 백업한다. 다른 등록 건물은 유지된다.

## 현재 제공 범위

- 건물·급배수·전기·소방·냉난방·임대차·유지보수·측정·문서·분석의 등록과 조회
- 예시 저수조, 펌프, 밸브, 층별 급수 분기, 분전반, 소화전, 실외기
- 확인 수준별 연결 표시, 좌표 범위·중복 ID·없는 연결 검증
- 이 브라우저의 localStorage 저장, JSON 백업/가져오기
- 실제 센서 수신, AI 추론, 회사 서버 동기화, 기존 케이스 자동 조회는 미연결
- 원본 파일은 업로드하지 않고 URL로 연결. 외부 URL은 클릭할 때만 열린다.

## 다음 단계

인증된 FM 건물·케이스 읽기/쓰기 → 문서 업로드와 권한 → 실제 센서 연동 → 근거를 제시하는 AI 조회 순서로 확장한다. 연결 계통만 보기와 선택 설비 확대는 제공한다.

## 평면도에서 배치

3D 아래 `평면도에서 배치`를 누른다. 층과 설비를 선택하고 평면을 클릭하면 위치를 지정한다. 배관 경로 모드에서는 시작 설비를 선택한 뒤 경유점을 순서대로 클릭한다. 층을 전환하며 다른 층의 경유점도 추가할 수 있다. 좌표 입력, 마지막 경유점 취소, 경로 비우기를 지원한다. `변경사항 저장 · 3D 반영`을 눌러 저장한다. 닫기는 이번 편집을 폐기한다.

도면은 JPG·PNG·WebP를 층별로 등록한다. 건물 외곽에 맞춰 여백을 자른 도면을 사용해야 하며, 전체 이미지가 건물 가로·세로에 대응한다. 이는 정밀 자동 도면 인식 또는 측량 기능이 아니다. 이미지와 좌표는 건물 JSON 백업에 포함된다. 설비를 이동하면 확인 상태를 추정으로 바꾸고 관련 경로 확인을 해제한다.

브라우저 저장은 v2 건물 목록 구조로 이전하며 기존 v1 원본은 삭제하지 않는다. 저장 자료 파싱 실패 시 덮어쓰기를 차단한다. 사진은 최대 1,000px로 압축하며 저장공간 부족 시 기존 데이터는 유지한다. 공유·권한 기능은 아직 없으므로 실제 임대차 개인정보는 회사 서버 권한 연결 이후 등록한다.
