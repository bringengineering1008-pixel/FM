# BRING 건물 설비지도 — 검토용 반영

## 변경 범위
- 회사 저장소 기본 브랜치를 기준으로 3D 설비지도 모듈을 추가한다. 기존 FM 화면에는 지도 링크, 건물정보 내보내기 버튼, 연결 스크립트만 추가한다.
- 다중 건물, 예시 건물, 층/설비 레이어, 평면 배치, 설비 복제, 점검 이력, 일정, 보고서, 백업·복원을 포함한다.
- FM에서 사용자가 선택한 건물명·주소만 JSON으로 내보내며, 3D 지도는 미리보기 확인 후 별도 빈 건물로 추가한다. 동일한 FM 이름·주소는 기존 지도를 연다.
- 연락처·계약·금액·고객 메모는 전송 대상이 아니다. 실측되지 않은 층수·치수는 임시 모형임을 표시한다.
- 기존 데이터베이스 규칙, 클라우드 설정, 다른 업무 화면의 로직은 변경하지 않는다.

## 검증 근거
- 단위 테스트: 29건 통과.
- 브라우저 스크립트: 12개 통과 (기본 CRUD, 카탈로그, 층 복제, 건물/사진/이력, 평면 배치, 둘러보기, 예시, 점검, 보고서/백업, 화면 크기, 위치 재확인, FM 이름·주소 이동).
- 회사 저장소의 분리된 로컬 서버를 대상으로 실행. `ATLAS_TEST_URL`로 대상 URL을 지정한다.
- 기존 사용 중인 로컬 서버에도 FM 이동 흐름을 별도로 검증했다.
- FM 이동 테스트는 외부 요청을 차단한 가상 로그인/가상 건물 자료로 실행했다. 실제 회사 계정의 건물 데이터 접근 성공을 의미하지 않는다.
- 화면에서 3D 렌더링을 확인했다. 기본 브랜치 병합이나 운영 배포는 수행하지 않는다.

## 남은 운영 범위
데이터는 각 브라우저에 저장된다. 자동 회사 서버 동기화, 직원별 접근권한, 실시간 센서, AI 진단은 연결되지 않았다. 실제 로그인 환경에서 내보내기 최종 수용 확인과 운영 보안 규칙 검토는 배포 전에 필요하다. 실제 도면 없이 만든 모델은 시공·차단·안전 판단 근거가 아니다.
