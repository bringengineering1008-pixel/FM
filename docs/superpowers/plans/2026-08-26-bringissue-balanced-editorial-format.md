# BringIssue Balanced Editorial Format Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 네이버 스마트에디터에 준비된 퇴직금·퇴직연금 글 두 편을 B 균형형으로 재편집하고, 모바일 검수를 거쳐 즉시 발행 및 예약발행 직전 상태로 만든다.

**Architecture:** 로컬 원고와 편집 디자인 문서를 기준 데이터로 사용하고, 로그인된 네이버 편집기의 두 탭을 각각 독립적으로 수정한다. 본문·이미지 순서는 보존하며 문단 여백, 소제목 이모티콘, 구분선, 밑줄, 노란 형광펜만 추가한 뒤 공개 설정과 예약 시간을 검증한다.

**Tech Stack:** 네이버 스마트에디터, 로그인된 Chrome 브라우저, Browser Use, 로컬 Markdown 원고

---

### Task 1: 편집 대상과 기준 고정

**Files:**
- Read: `docs/superpowers/specs/2026-08-26-bringissue-balanced-editorial-format-design.md`
- Read: `blog/2026-08-26-severance-pay-eligibility.md`
- Read: `blog/2026-08-25-retirement-pension-withdrawal.md`

- [ ] **Step 1: 두 원고의 제목과 이미지 순서를 대조한다**

퇴직금 글은 공식 이미지 4장, 퇴직연금 글은 이미지 13장이 원고 순서와 동일한지 확인한다.

- [ ] **Step 2: 강조 대상 문장을 고정한다**

퇴직금 글 형광펜 대상:

```text
1년 · 주 15시간 · 퇴직 후 14일
퇴직금 = 1일 평균임금 × 30일 × (총 재직일수 ÷ 365)
퇴직금은 퇴사 전에 자료를 모아 회사 계산표와 대조하는 것이 가장 빠릅니다.
```

퇴직연금 글 형광펜 대상:

```text
일시금과 연금은 세금 하나만 보고 고르면 안 됩니다.
퇴직급여 원금과 내가 추가로 납입한 돈은 과세 기준이 같지 않을 수 있습니다.
같은 날짜 기준으로 일시금과 연금의 세후 예상액을 모두 받아 비교하세요.
```

- [ ] **Step 3: 편집 전 두 탭의 자동저장 상태를 확인한다**

제목, 본문 마지막 문장, 이미지 개수, 현재 카테고리를 기록하고 다른 글의 자동저장 내용을 불러오지 않는다.

### Task 2: 퇴직금 글 B 균형형 편집

**Files:**
- Reference: `blog/2026-08-26-severance-pay-eligibility.md`
- Browser target: 네이버 글쓰기 탭 `퇴직금 지급기준, 1년·주 15시간·14일을 먼저 확인하세요`

- [ ] **Step 1: 문단 여백을 정리한다**

의미가 바뀌는 지점마다 빈 문단 한 줄을 남기고, 소제목 앞에는 두 줄, 뒤에는 한 줄의 여유를 둔다.

- [ ] **Step 2: 소제목을 B 균형형으로 바꾼다**

```text
✅ 먼저 숫자 세 개부터 기억하세요
📌 1. 근무기간과 주당 근로시간
💰 2. 평균임금 계산법
🔎 3. 계산에서 빠뜨리기 쉬운 항목
🗓️ 4. 퇴직 후 지급기한
✅ 5. 퇴사 전 체크리스트
```

- [ ] **Step 3: 큰 단락 사이에 구분선 4개를 삽입한다**

도입 요약 뒤, 제2절 앞, 제4절 앞, 체크리스트 앞에 네이버 구분선 컴포넌트를 넣는다.

- [ ] **Step 4: 핵심 문장에 밑줄과 노란 형광펜을 적용한다**

Task 1에서 정한 세 문장에는 노란 배경색을 적용하고, 계약서·급여명세서 보관 문장과 지급기일 합의 문장에는 밑줄을 적용한다. 한 문장에 두 효과를 겹치지 않는다.

- [ ] **Step 5: 공식 이미지 4장의 위치와 가독성을 확인한다**

제4조, 제8조, 고용노동부 계산 안내, 제9조 화면이 각각 관련 설명 바로 뒤에 있고 좌우가 잘리지 않는지 확인한다.

### Task 3: 퇴직연금 글 B 균형형 편집

**Files:**
- Reference: `blog/2026-08-25-retirement-pension-withdrawal.md`
- Browser target: 네이버 글쓰기 탭 `퇴직연금 수령방법, 일시금과 연금 중 무엇을 고를까`

- [ ] **Step 1: 문단 여백을 정리한다**

도입, 제도 설명, 비교, 결정 순서, 세금 주의, 질문 목록이 각각 독립된 블록으로 보이도록 빈 문단을 배치한다.

- [ ] **Step 2: 소제목을 B 균형형으로 바꾼다**

```text
✅ 먼저 결론부터 말씀드리면
📌 연금으로 받기 위한 기본 조건
🔎 DB·DC·IRP부터 구분하세요
💰 일시금과 연금의 차이
✅ 결정 전에 확인할 순서
⚠️ 같은 IRP라도 돈의 출처가 다릅니다
📋 금융회사에 물어볼 5가지
```

- [ ] **Step 3: 큰 단락 사이에 구분선 5개를 삽입한다**

도입 요약 뒤, 제도 구분 뒤, 세금 비교 앞, 결정 순서 앞, 금융회사 질문 앞에 네이버 구분선 컴포넌트를 넣는다.

- [ ] **Step 4: 핵심 문장에 밑줄과 노란 형광펜을 적용한다**

Task 1에서 정한 세 문장에 노란 배경색을 적용하고, 금융회사에 두 방식의 예상 세액을 요청하는 문장과 개인정보 가림 문장에는 밑줄을 적용한다.

- [ ] **Step 5: 이미지 13장의 위치와 가독성을 확인한다**

대표 이미지, 고용노동부 5장, 법령 2장, 비교표, 국세청 3장, 체크리스트가 원고 순서대로 남아 있고 캡션성 본문이 바로 이어지는지 확인한다.

### Task 4: 모바일·발행 설정 검수

**Files:**
- Browser target: 두 네이버 글쓰기 탭

- [ ] **Step 1: 모바일 화면으로 두 글을 처음부터 끝까지 확인한다**

문단이 5줄 이상 뭉치는 곳, 연속된 이모티콘, 겹친 강조, 잘린 이미지가 없는지 확인한다.

- [ ] **Step 2: 카테고리와 공개 범위를 확인한다**

두 글 모두 `오늘 뜬 유튜브` 카테고리, 전체공개, 검색허용 상태인지 확인한다. 별도 생활정보 카테고리가 아직 없다는 점은 발행 후 카테고리 개선 항목으로 남긴다.

- [ ] **Step 3: 즉시 발행 글 설정을 확인한다**

퇴직금 글의 발행 시간이 `현재`로 선택되어 있고 제목과 태그가 유지되는지 확인한다.

- [ ] **Step 4: 예약 발행 글 설정을 확인한다**

퇴직연금 글의 발행 시간이 `2026-08-26 19:30`으로 선택되어 있는지 확인한다.

- [ ] **Step 5: 최종 발행 버튼 직전에 사용자 확인을 요청한다**

확인 문구:

```text
두 글의 B 균형형 재편집과 모바일 검수가 끝났습니다. 지금 누르면 퇴직금 글은 즉시 공개되고, 퇴직연금 글은 2026년 8월 26일 19:30에 예약됩니다. 두 발행 버튼을 누를까요?
```

### Task 5: 승인 후 발행 결과 검증

**Files:**
- Browser target: 브링이슈 공개 글과 예약 글 목록

- [ ] **Step 1: 사용자 승인 후 즉시 발행 버튼을 누른다**

퇴직금 글이 공개 URL로 이동하는지 확인하고 `logNo`를 기록한다.

- [ ] **Step 2: 사용자 승인 후 예약 발행 버튼을 누른다**

퇴직연금 글이 예약 목록에 나타나고 예약 시간이 `2026-08-26 19:30`인지 확인한다.

- [ ] **Step 3: 공개 글의 모바일 화면을 다시 확인한다**

공개된 퇴직금 글에서 제목, 소제목, 구분선, 밑줄, 노란 형광펜, 이모티콘, 이미지 4장이 정상적으로 보이는지 확인한다.

- [ ] **Step 4: 공개 글을 텔레그램으로 전송한다**

공개 URL이 확인된 뒤 로컬 `automation.bringcare_telegram`의 `published` 명령에 제목, URL, `logNo`를 전달한다. 예약 글은 공개 전에는 보내지 않는다.
