# 브링이슈 네이버 블로그 브랜드 리디자인 설계

## 목표

브링이슈를 기존 경제 블로그와 무관한 구형 스킨에서 분리하고, `실시간 화제 유튜브 → 인물의 선택과 반전 해설 → 관련 아이템·수익 글 연결` 구조가 첫 화면에서 바로 이해되는 콘텐츠 브랜드로 전환한다.

## 승인된 방향

시각 방향은 `A. 에디토리얼 시그널`로 확정한다.

- 인상: 빠른 이슈 전달 + 에디터가 선별한 매거진의 신뢰감
- 핵심 문구: `지금 뜬 영상 속 결정적 한 장면`
- 블로그 설명: `사람들이 멈춰 본 장면, 그 뒤의 선택과 이유를 읽습니다.`
- 블로그명: `브링이슈 | 지금 뜬 영상 속 결정적 한 장면`
- 닉네임과 주소 `브링이슈`, `blog.naver.com/bringissue`는 유지한다.

## 시각 체계

### 색상

| 역할 | 색상 | 용도 |
|---|---|---|
| 메인 | `#14233B` | 커버, 썸네일 하단 바, 제목 배경 |
| 시그널 | `#FFCC36` | 짧은 라벨, 포인트 선, BI 프로필 배경 |
| 배경 | `#F4F1E8` | 블로그 전체 배경 |
| 표면 | `#FFFFFF` | 본문과 카드 영역 |
| 본문 글자 | `#172033` | 제목과 설명 |

흰색 본문 위 네이비 글자, 네이비 위 흰색 또는 노란색 조합만 사용한다. 기존 의류 사진 배경과 무관한 장식 이미지는 제거한다.

### 커버와 배경

- 커버 마스터: `1600 × 400px`, 네이비 단색 기반
- 왼쪽 안전영역에 `BRING ISSUE`와 핵심 문구 배치
- 노란색 가로 시그널 선을 로고 위에 사용
- 오른쪽은 원형 신호 그래픽을 15% 이하 투명도로 사용
- 배경 마스터: `1920 × 1200px`, 아이보리 중심의 매우 약한 네이비·노랑 기하 패턴
- 네이버 업로더가 다른 비율로 자를 경우 로고·문구는 중앙 60% 안전영역 안에 유지한다.

### 프로필

- 마스터: `600 × 600px`
- 노란색 원 안에 네이비 `BI` 모노그램
- 작은 크기에서도 읽히도록 다른 문구와 테두리 장식은 넣지 않는다.

## 카테고리 구조

기존 카테고리는 삭제하지 않고 이름과 순서만 바꿔 과거 연결을 보존한다.

| 현재 이름 | 변경 이름 | 역할 |
|---|---|---|
| 오늘 뜬 유튜브 | 오늘 뜬 유튜브 | 실시간 화제 영상과 홈피드용 주력 글 |
| 국내 경제 뉴스 | 스타·인물 비하인드 | 인물·관계·성격을 해설하는 검색형 글 |
| 국외 경제 뉴스 | 선택의 반전 | 선택 전후가 선명한 스토리형 글 |
| 경제 용어 및 기본적인 상식 | 돈 되는 아이템 | 영상과 자연스럽게 연결되는 검증 상품·브랜드 글 |
| 공지사항 | 브링이슈 안내 | 운영 원칙, 출처·광고 고지, 소개 |

표시 순서는 `오늘 뜬 유튜브 → 스타·인물 비하인드 → 선택의 반전 → 돈 되는 아이템 → 브링이슈 안내`로 한다.

## 대표 썸네일 시스템

### 고정 구조

- 원본 영상 캡처와 채널 워터마크를 유지한다.
- 유튜브 재생바·버튼·추천 UI는 넣지 않는다.
- 인물과 핵심 표정은 상단 약 70%에 둔다.
- 하단 약 30%에는 `#14233B` 75~82% 불투명 바를 사용한다.
- 상단 또는 하단 바 첫 줄에 노란색 소형 라벨을 둔다.
- 제목은 흰색 굵은 글씨, 최대 2줄, 약 18자 안팎으로 쓴다.
- 결말 전체를 밝히지 않고 사건·인물·반전 중 두 요소만 보여준다.

### 기존 공개글 5편

다음 글은 본문과 URL을 유지하고 첫 대표 이미지만 통일된 새 썸네일로 교체한다.

1. 유재석 4형제 군산 간짜장
2. 정재형·이적 남은 음식
3. 하지원 23년 만의 무대
4. 허경환 신인 시절 정수기
5. 이지현 미용실 직원 반전

본문의 장면 이미지 10장과 설명·출처·태그는 변경하지 않는다.

## 변경 범위와 비변경 범위

### 변경

- 블로그명과 소개 문구
- 프로필 이미지
- 커버·전체 배경
- 카테고리 이름과 표시 순서
- 기존 공개글 5편의 대표 이미지

### 유지

- 블로그 주소와 닉네임
- 공개글 제목·본문·댓글·공감·검색 허용 설정
- 각 글의 `오늘 뜬 유튜브` 카테고리
- 영상 원본 링크와 저작권 안내
- 기존 공개 URL

## 구현 안전 기준

- 공개글이나 카테고리를 삭제하지 않는다.
- 카테고리 이름 변경 전 현재 카테고리 번호와 글 수를 기록한다.
- 스킨 변경 과정에서 본문 폭과 모바일 표시가 깨지지 않는지 확인한다.
- 공개 프로필·스킨 저장과 공개글 대표 이미지 수정은 외부 공개 변경이므로 실제 저장 직전에 사용자 확인을 받는다.
- 한 글의 대표 이미지 교체 후 공개 화면을 검수한 다음 나머지 네 글에 반복한다.

## 완료 조건

- 공개 홈에서 기존 의류 사진 배경과 경제 카테고리명이 보이지 않는다.
- 블로그명, 커버, 프로필, 소개 문구가 같은 메시지와 색상을 사용한다.
- 카테고리 5개가 지정한 이름과 순서로 표시된다.
- 공개글 5편의 첫 대표 이미지가 동일한 썸네일 규칙을 따른다.
- 데스크톱과 모바일에서 제목·프로필·카테고리·대표 이미지가 잘리지 않는다.
- 공개글 5개 URL과 검색 허용 설정이 유지된다.
