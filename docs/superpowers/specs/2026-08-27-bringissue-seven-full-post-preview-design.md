# 브링이슈 7편 전체 전문 미리보기 설계

## 목적

예약 대기 중인 7편을 요약 카드가 아니라 실제 전체 원고 단위로 검토한다. 사용자는 한 화면에서 글을 선택하고 제목, 본문, 표, 공식 캡처, 강조 서식과 출처를 끝까지 확인할 수 있어야 한다.

## 선택한 방식

하나의 미리보기 페이지에 상단 글 선택 메뉴와 본문 영역을 둔다. 선택한 원고의 Markdown 파일을 불러와 블로그 폭으로 렌더링한다. 기존 통합 요약 미리보기는 일정과 전체 현황을 보는 용도로 유지하고, 각 글의 전문 검수는 새 페이지가 담당한다.

이 방식은 7개의 HTML 파일을 따로 만드는 방식보다 수정 반영이 빠르고, 한 페이지에 7편을 모두 이어 붙이는 방식보다 브라우저 렉과 긴 스크롤을 줄인다.

## 화면 구성

1. 상단 고정 메뉴
   - 예약 일시와 글 제목을 표시한다.
   - 현재 선택된 글을 명확하게 강조한다.
2. 글 정보 영역
   - 예약 일시, 주제 축, 검수 상태를 표시한다.
3. 전체 원고 영역
   - 제목과 문단은 가운데 정렬한다.
   - 소제목, 목록, 표는 읽기 편하도록 왼쪽 정렬을 허용한다.
   - `<mark>` 형광펜과 `<u>` 밑줄을 유지한다.
   - 공식 캡처는 원본 비율을 유지하고 가로폭만 화면에 맞춘다.
   - 캡션은 이미지 바로 아래에 표시한다.
4. 하단 검수 정보
   - 공식 출처 링크와 이미지 수를 표시한다.
   - 이전 글·다음 글 이동 버튼을 제공한다.

## 데이터 흐름

- 미리보기 페이지는 허용된 7개 Markdown 파일만 선택할 수 있다.
- 선택한 파일을 로컬 서버에서 읽는다.
- 제목, 소제목, 문단, 구분선, 목록, 표, 이미지, 태그를 변환한다.
- 이미지 경로는 Markdown 파일이 있는 `blog` 폴더를 기준으로 해석한다.
- 파일을 읽지 못하면 빈 화면 대신 오류 원인과 대상 파일명을 표시한다.

## 오류 처리

- 허용 목록에 없는 파일명은 불러오지 않는다.
- 이미지가 없으면 깨진 이미지 대신 ‘이미지 파일을 찾을 수 없습니다’라고 표시한다.
- Markdown 표의 열 수가 맞지 않으면 일반 문단으로 표시해 내용 유실을 막는다.
- 외부 링크는 새 탭으로 연다.

## 검증 기준

- 7편 모두 메뉴에서 선택된다.
- 각 글의 제목과 마지막 태그까지 렌더링된다.
- 모든 공식 이미지가 잘리지 않고 원본 비율로 보인다.
- 표가 모바일 폭에서 가로 스크롤로 확인된다.
- 형광펜, 밑줄, 이모티콘, 구분선이 유지된다.
- ‘그림 설명’, ‘영상의 n%’, ‘확인 기준일’ 금지 문구가 없다.
- 데스크톱과 모바일 크기에서 본문이 화면 밖으로 잘리지 않는다.

## 범위 제외

- 네이버 계정 로그인과 예약발행 조작
- 원고 내용 자동 수정
- 외부 인터넷 공개 배포
- 댓글, 조회수, 통계 기능
