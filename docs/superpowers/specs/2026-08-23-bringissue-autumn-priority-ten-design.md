# 브링이슈 가을·실시간 우선 10편 제작 설계

## 목표

2026년 8월 23일 기준 가을 선점형과 현재 화제형 콘텐츠 중 우선순위 10편을 제작한다. 핵심 독자는 30~50대이며, 화제만 요약하지 않고 가격·선택·예약·생활 행동으로 연결한다.

## 제작 대상

1. 2026 추석 기차표 예매 준비
2. 빅뱅 고양 콘서트 실제 총비용
3. 어벤져스 둠스데이 예고편 숨은 장면
4. 웨딩박람회 할인과 실제 계약비용
5. 추석 선물세트 구매 적기
6. 하윤경 내장탕 영상과 방문 판단
7. 홍성 대하축제 4인 가족 총비용
8. 유튜브 조회수 집계 방식 변경
9. 단풍 숙소 예약 적기와 취소표
10. 에어컨 시즌 종료 관리

## 중복 처리

- 기존 빅뱅 캠핑 글은 관계성과 팀워크가 주제이므로, 새 글은 고양 공연 관람 총비용과 선택 기준으로 분리한다.
- 기존 어벤져스 글은 닥터 둠의 정체와 상징이 중심이므로, 새 글은 예고편 장면별 단서와 관람 전 체크포인트로 분리한다.
- 기존 하윤경·레고 자산은 사실과 권리 상태를 다시 확인한 뒤 재사용할 수 있다. 동일 제목이나 동일 장면 배열은 사용하지 않는다.

## 글 형식

각 글은 다음 순서를 따른다.

1. 25~34자 안팎의 제목 훅
2. 자체 제작 대표 이미지 1장
3. 독자가 처한 장면으로 시작하는 3~5문단 도입
4. 공식 자료 또는 원본 영상 장면
5. `그림 → 장면 설명 → 편집자 해설` 반복
6. 가격·예약·선택 기준 비교
7. 노란 형광펜 핵심 문장 3~5개
8. 한 문장 결론과 단일 행동 요청
9. 공식 출처·원본 링크·광고 고지

본문은 가운데 정렬을 기본으로 하고 의미가 바뀌는 지점에 빈 문단을 둔다. 굵게, 밑줄, 이모티콘은 소제목과 핵심 문장에만 사용한다.

## 이미지 원칙

- 공식 사이트, 공식 영상, 직접 확인 가능한 공개 자료를 먼저 사용한다.
- 유튜브 캡처는 플레이어 버튼·진행바·추천 목록 등 UI가 보이지 않게 장면 자체만 정리한다.
- 한 글의 캡처는 6~10장으로 제한하고, 연속 장면을 원본 대체 수준으로 사용하지 않는다.
- 대표 이미지와 설명용 카드 이미지는 자체 제작한다. AI 이미지는 설명 이미지임을 내부 기록에 남기고 실제 현장처럼 표현하지 않는다.
- 인물 얼굴·상표·저작물은 불필요한 합성이나 왜곡을 하지 않는다.

## 사실 검증과 발행 게이트

- 가격, 일정, 예매, 요금, 제품 사양은 발행 당일 공식 페이지에서 다시 확인한다.
- 확인되지 않은 할인율, 총비용, 조회수, 순위는 제목에 쓰지 않는다.
- 각 글은 브리프 검증과 원고 검증을 통과해야 한다.
- 제휴 링크가 없는 글은 구매를 과장하지 않고 정보형으로 마무리한다.
- 공개 발행은 완성 원고와 이미지 검수 후 사용자의 최종 승인을 받아 진행한다.

## 제작 순서

시기가 짧은 `추석 기차표 → 유튜브 집계 변경 → 대하축제 → 빅뱅 공연 → 웨딩박람회`를 먼저 만들고, 나머지 5편을 이어서 제작한다. 공식 일정이 확인되지 않는 글은 검증대기로 분리하고 다음 순위 글로 대체한다.

## 완료 기준

- 10편 각각 제목, 최종 본문, 썸네일 문구 3개, 이미지 순서표, 출처, 태그, CTA를 갖춘다.
- 기존 공개·예약 글과 제목 약속 및 장면 배열이 중복되지 않는다.
- 형광펜, 밑줄, 이모티콘, 문단 여백이 기존 브링이슈 편집 매뉴얼에 맞게 표시된다.
- 발행 불가 요소와 추가 확인 사항이 글별로 분리되어 있다.
