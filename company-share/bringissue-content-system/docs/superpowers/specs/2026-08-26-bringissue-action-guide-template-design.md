# 브링이슈 행동 안내형 100점 글 템플릿 설계

## 목표

브링이슈 생활·금융 정보 글을 단순 제도 요약이 아니라 독자가 실제 화면을 보며 확인하고 행동할 수 있는 저장형 가이드로 만든다. 현재 연금저축·IRP 글을 첫 적용 사례로 삼고 이후 금융·건강검진·여행·디지털 문제 해결 글에 같은 품질 기준을 재사용한다.

## 선택한 접근

세 가지 접근을 비교했다.

1. 장식 강화형: 기존 글에 이모티콘·형광펜·이미지를 늘린다. 빠르지만 행동 가치가 낮다.
2. 공식 자료 요약형: 기관 화면과 설명을 촘촘히 배치한다. 신뢰도는 높지만 독자가 무엇을 해야 하는지 약하다.
3. 행동 동선형: 독자의 질문, 결론, 실제 확인 화면, 선택표, 예외, 체크리스트 순서로 구성한다.

행동 동선형을 채택한다. 장식은 정보 구조를 보조하고, 모든 이미지와 표는 독자의 한 가지 판단 또는 행동을 돕는다.

## 연금저축·IRP 글 재설계

### 독자 약속

연금저축 600만 원과 IRP 포함 900만 원의 관계를 이해하고, 본인 납입액·소득 구간·현금 여유를 확인해 납입 순서를 정할 수 있게 한다.

### 본문 순서

1. 실제로 헷갈리는 질문 두 개
2. 한 문장 결론과 30초 요약
3. 연금저축·IRP 조합을 보여 주는 네이버 표
4. 국세청 공식 표에서 600만 원·900만 원·15%·12%를 확인하는 화면
5. 본인 상황별 판단 세 가지
6. 최대 공제액과 실제 환급액의 차이
7. 중도인출·회사 부담금·ISA 전환 예외
8. 최종 확인 체크리스트
9. 저장 행동 한 가지

### 시각자료 원칙

- 이 글과 직접 관계없는 DB·DC·퇴직연금 수령 화면은 제거한다.
- 국세청 연금계좌 세액공제 표는 글자가 읽히도록 핵심 영역 중심으로 사용한다.
- 금융회사 앱 화면은 특정 회사 가입을 유도할 수 있으므로 공통 확인 항목을 설명하는 경우에만 사용한다.
- 이미지 안 정보는 본문에도 적고, 이미지 전후에 무엇을 봐야 하는지 설명한다.
- 유튜브 캡처는 공식 기관 영상이면서 현재 글의 판단을 직접 돕는 장면일 때만 사용한다.
- 사진 수는 고정하지 않는다. 이번 글은 핵심 근거 1~3장으로 제한한다.

### 네이버 편집 규칙

- 도입과 한 문장 결론은 가운데 정렬, 긴 설명·표·체크리스트는 왼쪽 정렬한다.
- 네이버 자체 표와 구분선만 사용한다.
- 노란 형광펜 2~3곳, 행동 문장 밑줄 2~3곳만 사용한다.
- 주요 소제목에만 이모티콘 한 개를 넣는다.
- 의미 묶음 사이에는 빈 문단 한 줄을 둔다.
- 같은 문장을 이미지 앞뒤에서 반복하지 않는다.

## 재사용 템플릿 구조

1. 제목: 대상 키워드 + 문제 + 얻는 답
2. 도입: 독자의 실제 질문
3. 결론: 한 문장 형광펜
4. 30초 요약
5. 실제 확인 화면
6. 네이버 자체 비교표
7. 상황별 선택 기준
8. 놓치기 쉬운 예외
9. 실행 순서 체크리스트
10. 주 CTA 한 가지

각 항목에는 `필수`, `조건부`, `금지` 규칙을 붙인다. 템플릿은 `blog/templates/bringissue-action-guide-template.md`에 저장한다.

## 완료 기준

- 제목의 질문에 도입 20% 안에서 답한다.
- 표가 네이버 자체 표로 보인다.
- 이미지가 관련 문장을 끊지 않는다.
- 이미지의 글자가 모바일에서 읽힌다.
- 관련 없는 자료와 출처 덤프가 없다.
- 형광펜·밑줄·이모티콘이 정해진 범위를 넘지 않는다.
- 독자가 글을 읽고 실행할 순서를 1분 안에 찾을 수 있다.
- 공개 화면에서 PC와 모바일 흐름을 모두 검수한다.

## 범위와 안전

- 특정 금융상품 가입이나 납입액을 개인에게 권유하지 않는다.
- 최대 세액공제액과 실제 환급액을 구분한다.
- 정책·세금 수치는 발행 당일 공식 자료로 확인한다.
- 공개 글 수정과 재발행은 사용자의 명시적 승인 범위에서만 수행한다.
