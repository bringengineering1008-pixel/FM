# 브링이슈 유튜브 홈피드형 5편 일괄 제작 설계

## 목표

2026년 8월 21일 기준 화제성이 확인된 유튜브 영상 5편을 선정하고, 각 영상을 무음으로 전체 분석해 네이버 블로그 공개 발행 직전 상태까지 완성한다.

## 고정 포맷

- 한 영상에서 독자가 궁금해할 핵심 반전 또는 관계 포인트 하나만 제목의 약속으로 삼는다.
- 대표 이미지는 인물·상황·짧은 문구가 한눈에 보이는 자체 편집 이미지로 만든다.
- 본문은 대표 이미지 이후 `장면 이미지 → 바로 아래 장면 설명 → 해설` 흐름을 반복한다.
- 장면 캡처는 원본의 영상 플레이어 UI를 제외하고 8~10장을 사용한다.
- 모바일 기준 1~3문장 단락, 의미 전환 시 빈 문단, 이모지 소제목, 굵게·밑줄 강조를 적용한다.
- 영상 대사를 길게 전재하지 않고 핵심 발언만 짧게 인용하며, 나머지는 맥락과 관찰을 덧붙여 재해석한다.
- 원본 채널·영상 제목·링크와 캡처 출처를 명시하고 워터마크를 제거하지 않는다.
- 모든 영상 분석·프레임 추출·검수 과정은 무음으로 진행한다.

## 선정 기준

- 당일 또는 최근 화제성이 검색 결과·조회수·인기 순위 중 하나 이상으로 확인될 것
- 공개적으로 확인 가능한 영상 내용만 다룰 것
- 범죄 피해 소비, 확인되지 않은 사생활·재산·의료 추측은 제외할 것
- 다섯 편의 중심 인물과 제목 각도가 과도하게 중복되지 않을 것
- 홈피드형 클릭 이유와 본문에서 실제로 제공할 정보가 일치할 것

## 네이버 설정

- 블로그: 브링이슈
- 카테고리: 오늘 뜬 유튜브
- 주제: 스타·연예인
- 전체공개, 검색·댓글·공감·블로그/카페 공유·외부 공유 허용
- 글마다 발행 설정 화면의 최종 `발행` 버튼을 누르기 직전에서 멈춘다.

## 완료 조건

각 글에 최종 제목, 대표 이미지, 8~10개 장면 이미지, 장면별 설명, 자연스러운 본문, 출처, 태그가 들어가 있고 네이버 발행 설정이 확인되어야 한다. 다섯 글 모두 공개 발행은 하지 않는다.
