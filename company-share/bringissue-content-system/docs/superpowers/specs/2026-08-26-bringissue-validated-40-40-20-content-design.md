# 브링이슈 검증 구조 우선형 40·40·20 콘텐츠 설계

## 목적

수익형 블로그 운영자가 제시한 검증 구조를 먼저 실행해 성과 데이터를 만든다. 초기에는 새로운 형식을 억지로 발명하지 않고, 검색 수요가 분명한 주제·클릭 이유가 명확한 제목·생활 문제 해결형 본문을 충실하게 따른다. 이후 실제 조회수와 유입 검색어가 확인된 부분에 브링이슈의 차별성을 더한다.

기존 공개 글은 누적 검색 성과를 관찰하기 위해 삭제하거나 대규모 수정하지 않는다. 신규 글부터 실험군으로 운영한다.

## 첫 실험 범위

첫 실험은 신규 글 10편이다.

- 고단가 주제 4편: 퇴직금·연금·보험·금융 피해처럼 광고 가치와 의사결정 의도가 함께 있는 질문
- 생활 문제 4편: 환불·고객센터·앱 오류·은행 이용처럼 지금 해결해야 하는 구체적인 문제
- 실시간 이슈 2편: 당일 관심이 붙었지만 독자에게 실제 정보 가치가 있는 생활·방송·인물 소재

실시간 이슈라도 확인되지 않은 사생활·재산·의료 정보, 범죄 피해 소비, 단순 기사 재작성은 제외한다.

## 주제 선정 흐름

1. 실제 검색어와 최근 공개 글의 성과를 확인한다.
2. 한 글에 한 독자, 한 문제, 한 약속만 배치한다.
3. 검색어가 넓으면 실제 행동이 필요한 세부 질문으로 좁힌다.
4. 정책·요금·금융·건강·안전 정보는 발행 당일 공식 자료로 다시 확인한다.
5. 공식 자료와 실제 화면을 확보하지 못하면 원고 작성과 발행을 보류한다.
6. 유사 주제는 연속 발행하지 않고 주제 쿨다운을 적용한다.

## 제목 공식

기본 공식은 `대상 키워드 + 독자가 처한 문제 + 바로 얻는 답`이다.

예시:

- 보이스피싱 계좌 지급정지, 돈이 빠져나갔다면 이 순서로 신고하세요
- 카카오톡 백업 안 됐을 때, 새 휴대폰에서 먼저 확인할 5가지
- 여행자보험 휴대품 손해, 휴대전화 파손이 보상되지 않는 경우

과장된 수익 약속, 근거 없는 숫자, 검색 순위 보장 표현은 사용하지 않는다.

## 본문 구조

모든 글은 다음 순서를 기본으로 한다.

1. 독자가 처한 실제 상황
2. 결론과 가장 먼저 할 행동
3. 공식 기준 또는 실제 서비스 화면
4. 사용자 관점의 단계별 처리 순서
5. 놓치기 쉬운 예외와 주의사항
6. 마지막 확인 체크리스트
7. 관련 글 또는 저장 중 하나의 행동

네이버 편집은 기존 B 균형형을 유지한다. 의미 단위 여백, 3~5개의 구분선, 소제목별 이모티콘 한 개, 노란 형광펜 2~3회, 행동 문장의 제한적 밑줄을 적용한다.

## 실제 캡처 원칙

- 유튜브 장면을 일반 설명 이미지로 대체하지 않는다.
- 정부기관·금융기관·서비스 운영사의 실제 사이트와 앱 화면을 우선한다.
- 독자가 절차를 따라가는 데 필요한 화면 수만큼 캡처하며 3장으로 제한하지 않는다.
- 각 캡처는 메뉴 위치나 확인 항목이 읽히도록 정돈하고 불필요한 브라우저 영역을 줄인다.
- 로그인 정보, 이름, 계좌, 연락처와 같은 개인정보는 공개 전에 가린다.
- 캡처 앞뒤 문단에서 화면에서 무엇을 확인해야 하는지 설명한다.
- `그림 설명`, `영상의 몇 % 지점` 같은 자동 생성형 문구는 사용하지 않는다.

## 차별화 시점

첫 10편에서는 검증된 구조를 우선한다. 차별화는 구조를 바꾸는 방식이 아니라 다음 요소를 추가하는 방식으로 시작한다.

- 40대 이상 독자가 헷갈리는 용어를 일상어로 번역
- 실제 공식 사이트의 클릭 동선
- 선택지별 비교표와 판단 기준
- 전화하거나 방문하기 전에 준비할 항목
- 공식 안내에서 놓치기 쉬운 예외

## 측정과 확대 기준

각 글은 발행 후 72시간과 7일에 확인한다.

- 조회수
- 검색 유입 비중
- 실제 유입 검색어
- 방문자 반응과 내부 이동
- 비슷한 기존 글 대비 성과

10편 가운데 성과 상위 주제와 제목 공식은 다음 묶음에서 비중을 높인다. 성과가 낮은 글은 즉시 삭제하지 않고, 검색 의도 불일치·제목 약속·근거·초반 이해도 중 원인을 진단한다. 30일 데이터가 쌓인 뒤 브링이슈 고유 형식의 확대 여부를 결정한다.

## 안전장치

- 금융상품 가입이나 투자수익을 권유·보장하지 않는다.
- 건강 글은 진단이나 치료 지시 대신 공식 준비사항과 의료기관 확인 필요성을 안내한다.
- 보험·환불·보상 결과는 약관과 개별 조건에 따라 달라질 수 있음을 밝힌다.
- 사실 확인이 끝나지 않은 글은 예약하거나 공개하지 않는다.
- 공개·예약 버튼은 사용자의 최종 발행 승인을 받은 뒤 누른다.

## 완료 기준

- 10편이 4·4·2 비율을 충족한다.
- 모든 글이 공식 출처와 실제 캡처 계획을 갖는다.
- 제목의 질문에 본문이 명확히 답한다.
- 각 글의 72시간·7일 성과를 같은 기준으로 기록한다.
- 다음 묶음의 주제 비중을 추측이 아니라 기록된 성과로 결정한다.
