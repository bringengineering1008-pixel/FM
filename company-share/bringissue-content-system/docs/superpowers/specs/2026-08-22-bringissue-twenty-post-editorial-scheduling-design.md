# 브링이슈 20편 전문 원고·고화질 캡처·예약 발행 설계

## 1. 목표와 확정 범위

- 브링이슈 네이버 블로그용 신규 묶음은 **총 20편**이다.
- 사용자가 승인한 `어벤져스: 둠스데이` 원고를 1번 기준본으로 삼고, 같은 품질 규칙으로 19편을 추가한다.
- 결과물은 원고, 출처 원장, 고화질 장면 이미지, 대표 이미지, 네이버 편집기 초안, 예약 발행 설정까지 포함한다.
- 실제 예약 발행 확정은 20편의 제목과 예약 시각을 사용자에게 보여 준 뒤 최종 확인을 받고 실행한다.
- 검색 또는 네이버 홈피드 노출은 보장하지 않는다.

## 2. 콘텐츠 포트폴리오

20편은 사용자가 선택한 `실시간 이슈형 안에 수익 연결형을 섞는 구조`로 편성한다.

| 역할 | 편수 | 목적 |
|---|---:|---|
| 연예인·화제 인물·영상 | 12 | 빠른 관심과 홈피드 발견 가능성 확보 |
| 최신 제품·생활 아이템 | 5 | 검색 수요와 승인된 제휴 상품 연결 가능성 확보 |
| 돈·소비·선택 이야기 | 3 | 브링이슈의 장기 검색 자산과 브랜드 관점 축적 |

1번 `어벤져스: 둠스데이` 글은 연예·영상 묶음에 포함한다. 나머지 후보는 제작 당일 공개된 유튜브 영상과 공식 자료를 기준으로 선정한다. 기존 발행 10편과 영상 ID, 핵심 인물, 제목 각도를 중복하지 않는다.

정치적 선동, 확인되지 않은 사생활·재산·건강 추측, 범죄 피해 소비, 혐오성 소재는 제외한다. 제품 글은 승인된 제휴 링크가 있을 때만 구매 행동을 넣고 광고 고지를 링크 앞에 배치한다.

## 3. 원고 기준: 매거진 스토리형 70% + 정보 해설형 30%

승인된 첫 원고의 읽기 리듬을 20편 공통 기준으로 사용한다.

1. 제목은 인물·사건·반전과 핵심 검색어를 함께 담되, 본문이 해결하지 않는 과장 약속은 쓰지 않는다.
2. 도입은 3~5개의 짧은 의미 묶음으로 구성하고, 첫 화면에서 `왜 지금 봐야 하는지`를 설명한다.
3. 본문 문단은 가운데 정렬을 기본으로 하며, 한 문단은 보통 20~45자, 최대 약 70자로 제한한다.
4. 모든 문장을 기계적으로 띄우지 않고, 장면·판단·의미가 전환될 때 빈 문단 하나를 둔다.
5. 장면 요약보다 편집자의 관찰·맥락·해석 비중을 높인다. 영상 대사를 연속 복사하지 않는다.
6. 의미 있는 인용구 또는 전환 블록을 2~3개 사용한다.
7. 굵게는 3~5회, 밑줄은 최대 1회, 이모티콘은 1~2개만 사용한다.
8. `그림 설명`, `브링이슈 해설`, `첫 컷은` 같은 반복형 템플릿 문구는 쓰지 않는다.
9. 결말은 독자가 의견을 남길 수 있는 구체적인 질문 하나로 끝낸다.
10. 원본 영상, 채널명, 작품 또는 제품의 공식 자료를 마지막에 명확히 연결한다.

## 4. 사진 배치와 고화질 캡처 기준

각 글은 대표 이미지 1장과 본문 장면 8~11장을 기본으로 한다. 실제 장면 수가 부족하면 억지로 개수를 채우지 않는다.

- 공개 영상에서 확보 가능한 최고 원본 해상도를 사용한다. 2160p 또는 1440p가 있으면 우선하고, 없으면 1080p를 사용한다.
- 본문 이미지는 원본 프레임에서 PNG 또는 JPEG 품질 95로 추출한다. 원본보다 무리하게 확대하지 않는다.
- 유튜브 재생 버튼, 진행 막대, 제목·추천 영상·댓글 등 플레이어 UI가 보이지 않도록 영상 프레임 영역만 자른다.
- 얼굴이 흐려진 프레임, 눈을 감은 순간, 장면 전환 중인 프레임, 같은 구도의 반복 이미지는 제외한다.
- 인물의 표정, 사건의 변화, 반전의 증거가 되는 서로 다른 장면을 선택한다.
- 영상 속 채널 워터마크나 출처 표시는 임의로 지우지 않는다.
- 사진 캡션은 8~20자 정도로 짧게 쓰고, 실질적인 설명은 일반 본문 문단에 둔다.
- 대표 이미지는 1600×900 원본을 만들고 모바일용 1:1 크롭에서도 인물과 핵심 문구가 잘리지 않게 안전 여백을 둔다.
- 긴 연속 영상이나 원본을 대체하는 클립은 재배포하지 않는다. 캡처는 비평·해설에 필요한 장면만 사용한다.

모든 추출 장면은 먼저 연락처 시트로 검수한다. 선명도, 중복, UI 노출, 자막 가독성, 표정, 워터마크를 확인한 뒤 최종 이미지만 네이버 편집기에 넣는다.

## 5. 편집기 구성

각 글은 다음 순서를 기본으로 한다.

`대표 이미지 → 짧은 훅 → 장면 → 짧은 설명 → 편집자 해석 → 인용구 전환 → 다음 장면 → 핵심 3줄 또는 비교 → 결론 질문 → 원본 출처 → 태그`

사진과 글이 교대로 보이게 배치하되, 사진 하나마다 반드시 별도의 제목을 붙이지 않는다. 독자가 스크롤할 때 `장면을 본다 → 의미를 읽는다 → 다음 장면이 궁금해진다`는 흐름이 이어지게 한다.

공통 설정은 `오늘 뜬 유튜브` 카테고리, `스타·연예인` 또는 글에 맞는 주제, 전체 공개, 댓글·공감·검색·외부 공유 허용이다. 제품·소비 글은 내용에 맞는 세부 카테고리와 주제를 사용한다.

## 6. 예약 발행안

예약 기간은 **2026년 8월 23일~24일**이다. 사용자 요청에 따라 하루 10편씩 배치한다. 한꺼번에 몰아 올리지 않고 각 게시물 사이를 약 90~120분 띄우며, 같은 유형과 인물이 연속하지 않게 섞는다.

| 날짜 | 예약 시각 |
|---|---|
| 8월 23일 | 07:30 / 09:00 / 10:30 / 12:00 / 13:30 / 15:00 / 16:30 / 18:00 / 20:00 / 22:00 |
| 8월 24일 | 07:30 / 09:00 / 10:30 / 12:00 / 13:30 / 15:00 / 16:30 / 18:00 / 20:00 / 22:00 |

가장 시의성이 높은 연예·영상 글은 8월 23일과 양일 저녁 시간에 우선 배치한다. 제품·생활 글은 오전과 점심, 장기 검색형 돈·선택 글은 오후에 섞는다. 하루 10편은 운영 강도가 높으므로 제목 패턴, 대표 이미지 문구, 인물, 출처 영상, 도입 문장을 모두 교차 검사한다. 실제 제작 시점에 소재가 급격히 낡았거나 사실관계가 바뀌면 해당 글은 예약하지 않고 같은 역할의 검증된 후보로 교체한다.

## 7. 자료 흐름과 기록

각 글은 다음 독립 단위를 가진다.

1. 후보 원장: 영상 URL, 채널, 게시일, 공개 반응, 중복 여부, 선정 이유
2. 사실 원장: 공식 출처, 확인일, 사용 가능한 사실과 인용 제한
3. 장면 원장: 타임스탬프, 장면 역할, 캡션, 원본 해상도, 검수 결과
4. 원고: 제목, 본문, 출처, 태그, 제휴 고지
5. 발행 원장: 카테고리, 주제, 공개 설정, 예약 시각, 최종 상태, 공개 URL

한 글의 실패가 다른 글의 원고나 자산을 덮어쓰지 않도록 글별 슬러그 폴더를 사용한다. 기존 10편 원장과 사용자의 미추적 파일은 수정하거나 삭제하지 않는다.

## 8. 검수와 실패 처리

예약 직전 다음 항목을 20편 모두 검사한다.

- 제목과 본문이 같은 약속을 다루는가
- 핵심 사실이 공식 자료 또는 원본 영상으로 확인되는가
- 사생활·건강·재산을 추측하지 않았는가
- 동일 영상·인물·제목 각도가 기존 글과 중복되지 않는가
- 문단 길이와 여백이 모바일에서 읽기 좋은가
- 굵게 3~5회, 밑줄 0~1회, 이모티콘 1~2회, 인용구 2~3회 범위인가
- 이미지가 선명하고 플레이어 UI와 중복 장면이 없는가
- 원본 링크, 채널명, 저작권 표시와 필요한 광고 고지가 있는가
- 카테고리, 주제, 전체 공개, 검색·댓글·공감·공유 설정이 맞는가
- 예약 날짜와 시간이 겹치지 않는가

영상 비공개, 자막·사실 검증 실패, 이미지 권리 불명확, 편집기 오류, 로그인 만료, CAPTCHA가 발생하면 해당 글의 예약을 중단한다. CAPTCHA는 사용자가 직접 처리한다. 예약 발행 버튼을 누르기 전에는 20편 제목과 최종 시간을 사용자에게 보여 주고 확인을 받는다.

## 9. 완료 기준

- 승인된 1번 원고와 같은 문체·형식으로 총 20편이 완성되어 있다.
- 각 글에 검증된 출처와 고화질 장면 이미지가 연결되어 있다.
- 20편이 네이버 편집기에서 모바일 형식 검수를 통과했다.
- 사용자 최종 확인 후 2026년 8월 23일~24일 하루 10편씩 예약 발행이 설정되어 있다.
- 발행 원장에 각 글의 예약 상태와 이후 공개 URL을 기록할 수 있다.
