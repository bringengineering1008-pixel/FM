# 브링이슈 제미나이 매거진 일러스트 적용 설계

## 1. 목적

브링이슈 본문에서 `기억하고, 골라서, 몰래 보냈다`처럼 문장만 크게 적은 정보 카드를 없앤다. 그 자리를 문단의 상황과 감정이 한눈에 이해되는 제미나이 생성 이미지로 대체한다. 실제 영상 캡처와 AI 일러스트를 구분해 신뢰도와 시각적 완성도를 함께 높인다.

## 2. 확정 스타일

- 기본 스타일: 세련된 한국 매거진 에디토리얼 일러스트
- 화면비: 16:9 가로형
- 권장 크기: 1200×675px 이상
- 톤: 밝고 고급스러운 색감, 자연스러운 공간감, 과하지 않은 드라마
- 금지: 웹툰 말풍선, 과한 3D 캐릭터, 텍스트가 가득한 카드, 실제 보도사진처럼 보이는 합성
- 이미지 안에는 제목이나 긴 문장을 넣지 않는다. 필요한 설명은 네이버 본문의 캡션으로 작성한다.

## 3. 실제 이미지와 AI 이미지의 역할

### 실제 영상·게시물 이미지

- 인물, 사건, 발언, 결과를 증명한다.
- 대표 이미지와 핵심 전환 장면에 우선 사용한다.
- 유튜브 재생바·버튼·댓글 등 UX/UI는 보이지 않게 캡처한다.

### 제미나이 매거진 일러스트

- 공개 영상에 없는 배경 상황이나 감정을 설명한다.
- 정보 카드가 들어가던 위치에 사용한다.
- 실제 인물의 얼굴을 정교하게 복제하지 않는다.
- 실존 인물이 등장해야 할 때는 인상·헤어·의상·분위기만 참고한 비식별 에디토리얼 인물로 표현한다.

## 4. 한 편의 권장 이미지 구성

- 자체 대표 이미지 1장
- 실제 영상 또는 공식 게시물 이미지 5~7장
- 제미나이 에디토리얼 일러스트 3~5장
- 총 9~12장을 기본 범위로 한다.
- 중요한 사실은 실제 이미지 옆에서 설명하고, 해석·배경·감정 문단에는 AI 이미지를 배치한다.

## 5. 본문 배치 규칙

1. 실제 장면
2. 장면에서 확인되는 사실 설명
3. 브링이슈의 해설
4. 제미나이 이해용 이미지
5. 이미지가 시각화한 맥락 설명

AI 이미지는 연속 두 장 이상 배치하지 않는다. 동일한 구도·인물·색감도 반복하지 않는다. 모든 AI 이미지 아래에는 `AI로 제작한 이해용 이미지입니다.`라는 캡션을 넣는다.

## 6. 제미나이 프롬프트 템플릿

```text
한국 온라인 매거진에 들어갈 16:9 가로형 에디토리얼 일러스트.

장면: [누가 / 어디서 / 무엇을 하는지]
핵심 감정: [놀람 / 배려 / 긴장 / 반전 / 따뜻함]
주요 소품: [문단을 설명하는 물건 1~3개]
구도: [와이드숏 / 미디엄숏 / 손과 소품 중심 / 공간 중심]
색감: 밝고 세련된 [크림·옐로 / 블루 / 피치] 계열.
스타일: 고급 라이프스타일 매거진 삽화, 자연스러운 빛, 충분한 여백,
현실적인 공간감, 섬세한 질감, 과하지 않은 표정.

실제 보도사진처럼 만들지 말 것.
실존 인물의 얼굴을 그대로 복제하지 말 것.
글자, 자막, 로고, 워터마크, 말풍선, 유튜브 UI를 넣지 말 것.
해상도 1200×675 이상.
```

## 7. 고윤정·리센느 글 교체안

기존 `card-02.jpg`부터 `card-10.jpg`까지의 문장형 카드는 최종 발행본에서 사용하지 않는다. 다음 다섯 장의 제미나이 일러스트로 교체한다.

1. 숙소 현관 앞에 큰 포장 물품이 비밀스럽게 도착한 장면
2. 새 숙소에 놓인 커다란 전신거울과 스툴 의자
3. 선배의 배려를 확인하고 놀라워하는 후배 아이돌의 뒷모습
4. 휴대전화 연락을 계기로 가까워진 선후배의 따뜻한 분위기
5. 팬심이 실제 인연으로 이어지는 과정을 상징하는 매거진 삽화

실제 얼굴 사진은 출처가 확인된 커뮤니티 원본 이미지에서만 사용한다.

## 8. 검수 기준

- 문장 전용 정보 카드가 남아 있지 않다.
- AI 이미지가 실제 사건의 증거처럼 배치되지 않았다.
- 실제 캡처와 AI 이미지의 역할이 본문만 읽어도 구분된다.
- 모든 AI 이미지에 고지 캡션이 있다.
- 이미지에 깨진 한글, 로고, 워터마크, 유튜브 UI가 없다.
- 같은 얼굴·구도·색감이 반복되지 않는다.
- 대표 이미지만 보아도 인물·사건·반전 중 두 가지 이상이 전달된다.

## 9. 매뉴얼 반영 범위

`브링이슈_유튜브_콘텐츠_운영_매뉴얼`의 장면·캡처 설계, 본문 템플릿, 저작권 원칙, 최종 체크리스트에 이 규칙을 추가한다. 신규 글 제작 스크립트와 원고 템플릿도 정보 카드 대신 `Gemini 이미지 프롬프트`와 `AI 이미지 고지 캡션`을 출력하도록 변경한다.
