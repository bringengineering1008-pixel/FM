# 브링이슈 예약글 19편 편집 규격 적용 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 이미 공개된 첫 글을 제외한 예약글 19편에 승인된 브링이슈 편집 디자인 규격을 적용하면서 기존 예약 날짜와 시간을 유지한다.

**Architecture:** 네이버 블로그 예약 발행 목록을 원장으로 삼아 각 글을 하나씩 수정한다. 수정 전 예약 시간을 기록하고, 본문 서식만 변경한 뒤 같은 예약 시간으로 다시 저장하며, 마지막에 예약 목록과 글별 서식을 교차 검수한다.

**Tech Stack:** 네이버 스마트에디터, 로그인된 인앱 브라우저, 로컬 예약글 원장

---

## 실행 결과

- 승인 후 16:20 예약글이 먼저 공개되어 실제 수정 대상은 예약 중인 18편으로 조정했다.
- 18편 모두 본문 16, 목차, 큰 번호 소제목 5개, 연한 노란색 형광펜 4곳을 적용했다.
- 모든 글에서 기존 이미지 10장과 원래 예약 시간을 유지했다.
- 작업 중 17:10 글이 공개되어 최종 확인 시 예약글은 17편이었으며, 공개된 17:10 글에도 새 목차가 반영된 것을 확인했다.
- 이미 공개된 15:30 및 16:20 글과 기존 2024년 임시글은 수정하지 않았다.

### Task 2: 글별 편집 규격 적용

**Files:**
- Reference: `docs/superpowers/specs/2026-08-22-bringissue-editorial-style-design.md`

- [ ] **Step 1: 예약글 수정 화면에서 대표 이미지와 도입부를 유지하고 목차를 추가한다.**

목차는 `🪧 목차`와 4~6개 번호 항목으로 구성하고 위아래에 구분선을 둔다.

- [ ] **Step 2: 본문을 번호 소제목 4~6개로 재배치한다.**

번호는 나눔바른히피 28 굵게, 소제목은 나눔바른히피 24 굵게, 본문은 나눔고딕 16으로 설정한다.

- [ ] **Step 3: 사진과 문장을 `사진 → 사실 설명 → 브링이슈 해설` 순서로 정돈한다.**

사진 앞뒤에는 한 줄을 비우고, 의미가 이어지는 문장 1~3개만 한 문단으로 묶는다.

- [ ] **Step 4: 연한 노란색 형광펜을 글마다 3~5곳 적용한다.**

도입 핵심 질문 1곳, 본문 전환·반전 1~3곳, 결론 1곳에 적용하며 밑줄·빨간색과 중복하지 않는다.

- [ ] **Step 5: 굵은 글씨, 밑줄, 이모티콘을 제한 규칙에 맞춰 정리한다.**

굵은 글씨는 핵심 결론과 숫자에 사용하고, 밑줄은 1~3회, 이모티콘은 목차·구역 전환·원본 영상·댓글 질문에만 사용한다.

- [ ] **Step 6: 원래 예약 날짜와 시간으로 수정 저장한다.**

예상 결과: 글 내용은 갱신되지만 예약 순서와 발행 시간은 변경되지 않는다.
