분석 대상: [네이버 블로그팀 공식 블로그](https://blog.naver.com/blogpeople)의 최신 공개 글 100편  
분석 기간: 2025년 3월 28일~2026년 8월 27일  
수집 결과: 목록 100편, 본문 분석 100편, 실패 0편  
원자료: `blog/research/blogpeople-latest-100.json`

## 먼저 알아둘 한계

- 이 블로그는 서비스 공지·이벤트·블로거 소개 비중이 높은 공식 운영 블로그다. 생활금융·문제 해결형인 브링이슈와 주제가 같지는 않다.
- 공개 조회수는 수집되지 않아 댓글 수를 참고 지표로만 보았다. 댓글이 많은 이벤트 글을 일반 정보글의 성과 공식으로 해석하지 않는다.
- 숫자는 비공개 네이버 알고리즘의 순위 요소가 아니라, 공개 글에서 관찰한 편집 습관이다.
- 따라서 문장·표현·구성을 복제하지 않고 모바일 가독성과 시리즈 운영 원리만 가져온다.

## 가져올 구조

### 1. 첫 화면에서 정체와 이익을 동시에 보여준다

`[짧은 시리즈명] + 구체적인 독자 문제 또는 결과`

- 시리즈 라벨은 `연금 한 장 정리`, `환불 바로 확인`, `여행 전 체크`처럼 8~12자 안에서 반복 가능할 때만 쓴다.
- 제목의 핵심 검색어는 라벨 밖의 자연스러운 문장에도 남긴다.
- 공지형 표현인 `소개합니다`, `공개합니다`는 브링이슈 검색정보 글에 남용하지 않는다.

### 2. 도입은 세 박자로 끝낸다

1. 독자가 처한 장면 또는 질문
2. 바로 필요한 결론
3. 글에서 확인할 순서

회사 인사, 긴 배경, 출처 목록으로 시작하지 않는다.

### 3. 짧은 문단과 시각적 쉼표를 사용한다

- 한 문단은 한 판단 또는 한 행동을 담당한다.
- 1~3개의 짧은 문장이 같은 의미를 설명하면 한 묶음으로 둔다.
- 대상·상황·판단·행동이 바뀔 때 빈 문단 또는 네이버 자체 구분선을 사용한다.
- 구분선은 기본 2개 안팎이며 글의 실제 정보 블록 수에 따라 조정한다.

### 4. 이미지는 장수가 아니라 역할로 배치한다

최소 역할은 다음 중 하나다.

- 대표: 무엇을 해결하는 글인지 한눈에 설명
- 근거: 공식 사이트·앱에서 실제로 확인되는 위치 증명
- 행동: 독자가 다음에 눌러야 할 메뉴나 입력해야 할 항목 안내
- 비교: 선택지 차이를 한 화면에서 정리
- 예외: 놓치기 쉬운 조건과 위험 표시

실제 화면은 잘리지 않고 글자가 읽혀야 한다. AI·Google Flow 이미지는 대표·설명·비교 보조에는 사용할 수 있지만 공식 근거 화면을 대체할 수 없다.

### 5. 반복 시리즈로 다음 글을 기다리게 한다

- 한 주제는 총론 1편과 세부 질문 3~6편으로 묶는다.
- 시리즈 라벨·대표색·마무리 위치는 유지하되 제목과 도입 문장을 복붙하지 않는다.
- 관련 글은 독자의 다음 질문에 답하는 1~2편만 연결한다.

## 가져오지 않을 것

- 이벤트성 댓글을 일반 정보글 성과로 해석하기
- 모든 제목에 대괄호·숫자·이모지를 동시에 넣기
- 공식 블로그의 공지 말투를 생활금융 글에 그대로 사용하기
- 이미지 3장, 구분선 2개, 이모지 2개를 기계적인 정답으로 만들기
- 표가 필요하지 않은 설명을 표로 포장하기
- 영상 캡처나 AI 이미지를 공식 사이트 근거 대신 사용하기

## 브링이슈 편집 기본값

| 구성 요소 | 기본값 | 늘리거나 줄이는 조건 |
|---|---|---|
| 도입 | 장면 → 결론 → 읽을 순서 | 긴 정책 배경은 본문으로 이동 |
| 모바일 문단 | 1~3문장, 한 의미 묶음 | 단계·주의가 바뀌면 새 문단 |
| 구분선 | 2개 안팎 | 짧은 글 1개, 긴 행동 안내형 최대 4개 |
| 이모지 | 1~3개 | 제목에는 검색 의도를 방해하지 않을 때만 0~1개 |
| 이미지 | 역할 수만큼 | 공식 화면이 여러 단계면 필요한 만큼 추가 |
| 링크 | 공식 행동 링크·관련 글 1~2개 | 근거가 여러 개여도 본문 끝 URL 덤프 금지 |
| 표 | 조건부 1개 | 동일 기준으로 2개 이상 선택지를 비교할 때만 |
| 인용구 | 조건부 0~1개 | 최종 판단 한 문장에만 사용 |

## 실제 사용 이모티콘

100편의 제목과 본문에서 실제 확인된 상위 문자는 다음과 같다.

- 축하·새 소식: ✨ 26회, 🎉 24회, 🍀 22회, 🎁 13회, 🚀 10회
- 일정·안내: 🗓️ 24회, 📌 13회, 📍 13회, 📝 13회, 📢 5회, 🔔 5회
- 궁금증·확인: 👀 10회, 🤔 7회, 💡 5회, 🔍 4회
- 주의·완료: ❗ 8회, ✔️ 7회, ⚠️ 6회, ✅ 6회
- 금액·혜택: 💰 7회, 🍯 5회

브링이슈는 이 가운데 `📌 / 🔍 / 💡 / ⚠️ / ✅ / 💰 / 🗓️`를 생활정보 글의 기본 후보로 사용한다. 실제 주제가 축하·새 소식일 때만 `🎉 / ✨ / 🍀 / 🎁`을 사용한다.

## 발행 전 추가 확인

- [ ] 제목 라벨·숫자·이모지는 실제 정보와 시리즈 목적이 있을 때만 썼다.
- [ ] 도입 세 문단 안에서 독자 장면·결론·읽을 순서가 보인다.
- [ ] 각 이미지에 대표·근거·행동·비교·예외 중 하나의 역할이 있다.
- [ ] 구분선·이모지·표를 관찰 중앙값에 맞추려고 억지로 넣지 않았다.
- [ ] 공식 화면이 잘리지 않고 모바일에서 글자를 읽을 수 있다.
- [ ] 시리즈 글은 이전 글을 복사하지 않고 다음 질문을 해결한다.
