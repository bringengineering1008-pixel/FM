# 브링이슈 콘텐츠 시스템 보관 폴더

이 폴더는 브링이슈 네이버 블로그 작업 자료를 회사 저장소 안에서 독립적으로 관리하기 위한 공간입니다.

## 포함 대상

- 최종 원고와 발행용 초안
- 브리프·예약 발행 원장·성과 원장
- 작성 매뉴얼·템플릿
- 자동화 및 검증 스크립트
- 게시에 실제 사용한 이미지와 공식 화면

## 제외 대상

- 로그인 정보·쿠키·인증 코드·API 토큰
- 텔레그램 토큰·Chat ID·전송 상태
- 임시 파일과 로컬 도구 캐시
- 원본 유튜브 영상과 불필요한 대용량 중간 산출물
- 다른 회사 프로젝트 파일

## 운영 원칙

- 회사 저장소의 기존 폴더를 수정하거나 이동하지 않습니다.
- 업로드는 `codex/bringissue-content-archive` 별도 브랜치에서 진행합니다.
- 검수 후 필요한 경우에만 회사 담당자가 기본 브랜치에 병합합니다.
